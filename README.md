# STUDENT OS — نظام تشغيل الطالب

تطبيق ويب تقدّمي (PWA) عربي RTL لطلاب الثانوية: منهج، مهام ومواعيد، تركيز، مكتبة شخصية، أدوات تقنية، ومساعد ذكي قابل للربط. **بدون حسابات، بدون خادم، بدون مكتبات خارجية، وبدون Build.** كل البيانات تُحفظ على جهاز المستخدم.

HTML5 + CSS3 + Vanilla JavaScript (ES Modules) + LocalStorage + IndexedDB + Manifest + Service Worker.

## الأقسام وحالتها

| القسم | الحالة |
|---|---|
| لوحة التحكم | ✅ ترحيب، مهام اليوم، إنجاز المنهج، أقرب امتحان، وقت المذاكرة، نشاط أخير، اختصارات |
| منهجي | ✅ مواد ← وحدات ← دروس، حالة، إتقان (0–5)، ملاحظات، موعد مراجعة، نسب إنجاز ورسوم. **لا يحتوي أي محتوى رسمي**: كل شيء يضيفه المستخدم |
| المساعد الذكي | ⚠️ الواجهة والبنية جاهزة وتعمل، لكنه **غير مربوط بأي مزود** حتى تربطه (انظر `docs/ai-proxy-example.md`). يعرض ذلك بوضوح ولا يُنتج إجابات وهمية |
| مخططي | ✅ يومي/أسبوعي/شهري، حصص متكررة، امتحانات، مهام بأولويات ومواعيد، المتأخرة |
| التركيز | ✅ Pomodoro قابل للتخصيص يستمر في الخلفية، تسجيل تلقائي ويدوي، إحصاءات يومية وأسبوعية وحسب المادة |
| مكتبتي | ✅ ملاحظات مصنفة، روابط، ملفات (IndexedDB)، بحث موحّد |
| الأدوات | ✅ حاسبة علمية، محرر HTML/CSS/JS (معزول)، منسق JSON، عداد كلمات، تحويل وحدات، مولد كلمات مرور، معالجة وتنسيق النصوص |
| الإعدادات | ✅ الاسم والصف والمظهر، ربط المساعد، تصدير/استيراد JSON مع تحقق، نسخ داخلية، حذف كل البيانات بتأكيد كتابي |

## التشغيل محليًا

ملفات ES Modules و Service Worker لا تعمل بفتح `index.html` مباشرة (`file://`). استخدم أي خادم ثابت:

```bash
cd student-os
python3 -m http.server 8000      # أو: npx serve .
# افتح http://localhost:8000
```

`localhost` يُعامل كسياق آمن فيعمل الـ Service Worker والتثبيت.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا (مثل `student-os`) وارفع **محتويات** مجلد المشروع إلى جذر المستودع (يجب أن يكون `index.html` في الجذر).
2. من **Settings ← Pages** اختر **Deploy from a branch**، الفرع `main`، والمجلد `/ (root)`.
3. بعد دقائق يعمل التطبيق على `https://USERNAME.github.io/student-os/`.

كل المسارات في المشروع **نسبية** (`css/style.css`، `js/app.js`، `./`) والتنقل يعتمد على `#/route`، لذا يعمل داخل أي مسار فرعي دون تعديل. الملف `.nojekyll` موجود لتجنب معالجة Jekyll.

### التثبيت على أندرويد
افتح الرابط في Chrome ← قائمة ⋮ ← **تثبيت التطبيق**. يعمل بعدها بملء الشاشة ودون إنترنت.

## تحديث التطبيق بأمان

بعد **أي** تعديل على الملفات شغّل:

```bash
node scripts/build-sw.mjs
```

يحسب هذا السكربت (Node فقط، بدون حزم) بصمة لمحتوى الملفات ويحدّث `sw.js` بقائمة التخزين المسبق ورقم إصدار جديد. عند فتح المستخدمين للتطبيق تُنزَّل النسخة الجديدة بالكامل في ذاكرة مستقلة، ثم تظهر رسالة **«يتوفر إصدار جديد — تحديث الآن»**؛ فلا يحدث خلط بين ملفات قديمة وجديدة. إن نسيت تشغيله فسيبقى المستخدمون على النسخة المخزنة القديمة.

## البيانات والخصوصية

- الحالة الرئيسية في `localStorage` (مفتاح `studentos.v1`) وتُحفظ تلقائيًا؛ الملفات والنسخ الداخلية في IndexedDB.
- كل ما يُقرأ من التخزين أو من ملف مستورد يمر عبر `lib/schema.js` الذي يتحقق من الأنواع والحدود ويتجاهل العناصر التالفة بدل أن ينهار التطبيق.
- النسخة الاحتياطية JSON: `{ app, schemaVersion, exportedAt, data, files[] }`. يرفض الاستيراد ملفًا ليس من STUDENT OS أو بإصدار أحدث، ويعرض معاينة قبل الاستبدال ويحفظ نسخة داخلية تلقائيًا للتراجع.
- لا تتبّع ولا إحصاءات. الاتصال الخارجي الوحيد هو خدمة المساعد **إن ربطتها أنت**.
- القوالب تهرّب كل نص مستخدم تلقائيًا (`lib/html.js`) لمنع حقن HTML. محررات HTML/CSS تعمل في iframe معزول بدون `allow-same-origin`، ومحرر JS داخل Web Worker يُنهى بعد 5 ثوانٍ.

## حدود معروفة

- المساعد الذكي غير مربوط افتراضيًا (بقرار تصميمي صريح).
- التخزين المحلي مرتبط بالمتصفح والجهاز: لا مزامنة بين الأجهزة. استخدم التصدير/الاستيراد.
- المؤقت يعتمد على الطوابع الزمنية فيبقى دقيقًا، لكن أندرويد قد يمنع صوت التنبيه والصفحة في الخلفية؛ يُعرض إشعار داخل التطبيق عند العودة.
- الاختبار الآلي أُجري على Chromium. لم يُجرَّب على أجهزة أندرويد أو iOS الفعلية ولا على Firefox/Safari.
